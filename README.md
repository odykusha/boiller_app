# Бойлер Монітор - Android Додаток

Android додаток для моніторингу даних інвертера з відображенням графіків у реальному часі.

## Можливості

- 📊 Відображення графіків для:
  - Батарея (SOC %)
  - Мережа (Вт)
  - Дім (Вт)
- 📱 Картки з поточними значеннями
- 🔄 Автоматичне оновлення кожні 60 секунд
- ⚙️ Налаштування URL сервера
- 🎨 Сучасний темний інтерфейс

## Вимоги

- Android Studio Hedgehog (2023.1.1) або новіша версія
- Android SDK 24 (Android 7.0) або вище
- Kotlin 1.9.20+
- Gradle 8.2+

## Встановлення

1. Відкрийте проект в Android Studio
2. Синхронізуйте Gradle файли
3. Підключіть Android пристрій або запустіть емулятор
4. Натисніть Run (▶️) для збірки та встановлення додатку

## Налаштування

### URL сервера

За замовчуванням додаток підключається до `http://192.168.50.160:5000/`

Для зміни URL:
1. Натисніть на іконку налаштувань (⚙️) в верхньому лівому куті
2. Введіть новий URL сервера
3. Натисніть "Зберегти"

**Важливо:** URL повинен закінчуватися на `/` та бути доступним з вашого Android пристрою.

### Налаштування web_server.py

Переконайтеся, що `web_server.py` запущений та доступний з вашої мережі:

```bash
# Запуск сервера
python web_server.py
```

Сервер буде доступний на `http://0.0.0.0:5000` (за замовчуванням).

## API Endpoints

Додаток використовує наступні endpoints з `web_server.py`:

- `GET /api/data` - Отримання історії даних
- `GET /api/latest` - Отримання останніх даних
